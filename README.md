# Jev 聊天助手

对方私聊发消息后，本地秒判意图/危险等级/情绪，可选接入任意 OpenAI 兼容大模型，给出 3 条候选回复并自动复制到剪贴板，你手动粘贴发送。

**绝不自动发消息，只私聊不群聊。**

---

## 各版本适配

| 版本 | 适配框架 | 脚本位置 |
|---|---|---|
| QStory 版 | QStory（Xposed 模块） | QStory 脚本管理界面内导入 |
| Nuke 版 | Nuke（JS 脚本框架） | Nuke 脚本管理界面内导入 |
| WA 版 | WAuxiliary（微信模块） | `/sdcard/Android/data/com.tencent.mm/WA/scripts/` 下新建文件夹 |
| WeKit 版 | WeKit（微信模块） | `/sdcard/Android/data/com.tencent.mm/WeKit/scripts_java/` 下新建文件夹 |

---

## 安装步骤（WA / WeKit 通用）

1. 下载对应版本的 zip。
2. **解压到脚本地址目录**：脚本目录一个文件夹对应一个脚本，文件夹叫什么脚本就会显示什么，每个文件夹下面包含该脚本的全部文件（main.java、info.prop、readme.md）。**不要直接把脚本文件散解压到模块的脚本地址**，模块只认脚本地址下的文件夹名。
   - 例：WeKit 版 → 在 `scripts_java/` 下建一个 `jev/` 文件夹，把 `main.java`、`info.prop`、`readme.md` 放进去。
3. **放好脚本后必须强制结束微信，再重新打开微信**，否则模块不会加载新脚本。
4. 打开微信任意私聊，输入 `/jev` 发送，弹出配置界面。

## 配置项说明

### 作用域（开启本会话 = 第一轮开关）
- 打开后，当前这个聊天窗口收到对方消息就会自动跑第一轮本地判断（意图/危险/情绪）。
- 关掉则这个会话不做任何分析。

### 第二轮决策开关（更聪明版）
- 关掉：只跑第一轮本地判断，不调用大模型。
- 打开：收到消息后经过 3 秒防抖（等对方把连续消息发完），自动调用大模型给建议和 3 条候选回复。

### 大模型分析前手动确认（弹窗）
- 打开：收到消息后先弹一个对话框，显示"对方说了什么 + 本地判断"，你点"分析"才调大模型。
- 关掉：收到消息后 3 秒自动调大模型，不弹窗确认。

### 撤回第一轮本地判断
- 打开：大模型结果出来后，撤回之前那条本地判断的灰字，替换成大模型的完整建议。
- 关掉：第一轮灰字保留，大模型结果追加在下面。

### 关闭聊天灰字（结果只走弹窗）
- 打开：不在聊天界面插灰字，所有结果都用弹窗显示。
- 关掉：结果以系统消息形式插在聊天记录里。

### API 配置
- **API 地址**：任意 OpenAI 兼容接口的 `/v1` 结尾地址，例如 `https://api.xiaomimimo.com/v1`、`https://right.codes/v1`。
- **API 密钥**：`sk-` 开头的密钥。
- **模型名**：如 `mimo-v2.6-flash`、`deepseek-chat`、`deepseek-v4-flash`、`qwen-plus`。建议用非推理类模型（flash/chat 结尾的）响应更快；推理模型（如 deepseek-r1 / v4-flash）思考慢但更准。
- **关系补充说明**：自由文本，告诉大模型对方和你是什么关系，例如"对方是我男女朋友，认识半年"。留空则用默认值"对方是我的关系亲密的对象"。
- **上下文轮数**：发给大模型的最近消息条数（含双方）。WeKit 默认 10，WA 版不读历史（只分析当前这条）。
- **排版宽度**：灰字每行宽度，0 = 自动适配屏幕。

## 使用方法

1. 进入任意私聊，输入 `/jev` 发送打开配置。
2. 点"本会话：未开启"开启作用域（同时开启第一轮判断）。
3. 打开"第二轮决策开关"接入大模型，填好 API 地址/密钥/模型。
4. 对方发消息后：
   - 第一轮：聊天里立刻出现一行灰字（意图 · 危险x/9 · 情绪 x%）。
   - 第二轮（如开了大模型）：3 秒后弹出或插入大模型建议，3 条候选回复自动复制到剪贴板。
5. 长按输入框粘贴，选择合适的那条发送。

---

## 推荐模型

追求速度：`mimo-v2.6-flash`、`deepseek-chat`、`qwen-turbo`
追求质量：`deepseek-v4-flash`（推理模型，慢但更准）、`qwen-plus`

---

## 注意事项

- 只分析私聊，群聊消息自动跳过。
- 不读语音和表情包，只分析文字。
- 候选回复自动复制到剪贴板，不会自动发送。
- 如大模型无返回，检查 API 地址/密钥是否正确、模型名是否存在。
